## データの流れ

```text
PS5 USB／Pi CAN2 → 操作入力と操作権限の管理
IMU I2C、RS06 CAN1、C620 CAN2、F303電源状態
                ↓
        センサ値の時刻付き取り込み
                ↓
       状態推定・6節リンク計算（500 Hz）
                ↓
    LQR＋脚長PD＋Roll PD＋Yaw PI（500 Hz）
                ↓
      VMC・ガスシリンダ補償・各RS06個別上限
                ├→ RS06 CAN1：4台×250 Hz
                └→ C620 CAN2：2台×500 Hz

安全監視が最終的な駆動許可を決定する。
F303の電源・非常停止状態機械は独立動作する。
```

## モジュール別の責務

| 分野 | 責務 | 仕様ID |
|---|---|---|
| ボードドライバ | CAN、I2C、USB、タイマ、IWDG、送受信 | BOARD-F446-001／BOARD-F303-001 |
| 通信プロトコル | CAN ID、バイト順、量子化、受信値検証 | PROTO-* |
| 状態推定 | センサ入力を物理状態へ変換。モータ指令は生成しない | CTRL-EST-001 |
| 制御器 | 状態から抽象トルク・脚力を計算。CANフレームは組まない | CTRL-LQR-001 |
| 駆動配分 | 関節・車輪への換算、個別飽和、診断 | CTRL-LQR-001 |
| 安全・状態機械 | DISARMED／BALANCING／FAULT、ARM許可、操作元権限 | BEHAV-001 |
| 診断 | 制御時間、新規測定、飽和、故障原因 | BOARD-F446-001 |

## 周期・安全境界

- 500 Hzは演算周期であり、センサ値が500 Hzで更新される保証ではない。
- RS06角度・角速度は受信の合間に最新値を保持する。各軸30 ms受信断でFAULT。
- M3508は20 ms、BNO055の**新しい有効測定値**は50 ms、F303電源報告は500 msを監視する。
- LQR用の車輪基本トルクを優先し、余剰分でYawを制御する。**脚RS06側には複雑なRoll残余トルク優先配分を追加せず、最終モータトルクを個別制限する**（MOTOR-163）。
- RS06各軸のCAN送信完了とフィードバック受信、M3508共通フレーム送信完了と左右受信を監視する。通信断とは別に送信詰まりも異常とする（MOTOR-191,194）。
- PS5通信復旧はニュートラル安定確認後に**操作だけ**自動復帰し、FAULT解除と再ARMは明示操作を要求（MOTOR-149,154,155）。
- モータ符号、センサ取付向き、機械原点、減速効率、電流制限、`K_300`は測定前に安全な既定値と見なさない。
- 実機試験は必ず支持治具から開始する。FAULTでトルクを停止すると機体が転倒する可能性がある。
