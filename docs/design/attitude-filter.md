# 姿勢推定：加速度とジャイロの相補フィルタ

BNO055のACCGYROモードを想定した**HAL非依存の数学処理**です。実I2C読出しやBNO055の新規サンプル判定はまだ接続していません。

## 推定の流れ

<pre class="mermaid">
flowchart LR
    SENSOR["校正済み加速度・ジャイロ"] --> AXIS["検証済み取付軸の変換"]
    AXIS --> BIAS["静止確認済みサンプルでバイアス平均"]
    BIAS --> FILTER["ジャイロ予測と重力角度の相補補正"]
    FILTER --> OUT["Pitch・Roll・Yaw角速度"]
</pre>

機体のX前・Y左・Z上を数学上の座標系として使います。センサの実際の取付方向は未確認なので、3軸の入替・符号を設定として与えます。鏡像になってしまう軸変換は拒否します。

## 計算するもの

| 出力 | 計算 | 限界 |
|---|---|---|
| Pitch・Roll | ジャイロ積分予測と加速度重力方向の相補補正 | 加速度外乱時はジャイロ予測のみ |
| Pitch・Roll角速度 | バイアス補正済み機体Y/X軸ジャイロ | 小角近似であり、厳密なEuler角の時間微分ではない |
| Yaw角速度 | バイアス補正済み機体Z軸ジャイロ | 絶対Yaw角・厳密なEuler Yaw微分ではない |
| 元の測定時刻 | 新規サンプルの時刻を保持 | 500 Hzティックで偽の更新時刻を付けない |

相補フィルタは、**予測角と加速度角の差を±πの最短角度として計算**します。ジャイロX/YをそれぞれRoll/Pitchの角度変化として積分する処理は小角近似で、傾きが大きい状態やYawと結合した3次元運動の厳密なEuler運動学ではありません。重力ノルムが指定範囲外の場合は加速度による補正を行いません。測定時刻の逆行や長い入力途絶は、推測で補間せず拒否します。

## 実機に使う前の条件

フィルタ係数、静止サンプル数、重力ノルム範囲、更新間隔上限はホスト専用の人工値で検証しています。BNO055の取付方向、I2C実測定タイミング、静止判定、ジャイロの温度ドリフトを確認するまで、実機BALANCINGの検証済み姿勢として使いません。
