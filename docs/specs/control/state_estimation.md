# 状態推定・六節リンク運動学

**仕様ID:** CTRL-EST-001  
**更新日:** 2026-11-09  
**状態:** 入出力と推定方式は設計決定済み。CAD幾何、原点、角度範囲、ヤコビアン、実機符号は未検証。

## 計算の境界

- CAN・I2C・USB受信は非同期に行い、センサごとに時刻付きの最新サンプルを保持する。
- 500 Hzの制御周期の先頭で、同一周期に使用する読取専用スナップショットを固定する。センサ自体が500 Hzで新規測定するという意味ではない。
- 受信原値→モータ軸の物理量→機構の入力軸→片脚の幾何状態→LQRの状態という順に変換する。減速比・符号の設定と機械原点の校正を分離する。

## 脚の運動学

- 左右各脚は**RS06 2台を協調させる六節リンク**。2台が同様に動く共通成分が脚全体の回転、差動成分が膝の屈伸に対応する。ただし実関節角・脚長への変換はCADに基づく非線形運動学で求める。
- モータ入力軸、外部16:24チェーン、機械原点、角度符号を区別する。RS06の報告角が電源再投入後にどの軸の多回転量を保持するかは**実機確認事項**。組立時の原点登録を想定するが、再起動後の原点再現性を確認するまで自動ARMを許可しない。
- 腰側は機構上連続回転が可能で、膝側には機械的な限界がある。六節リンクの分岐、実可動域、特異姿勢はCADと実機で確認する。
- 左右の実脚長 `L`、脚の前後傾斜 `θ`、脚長速度 `dL/dt`、仮想脚角速度を片脚ごとに計算する。脚長速度はRS06角速度と解析ヤコビアンから算出し、初期実装ではローパスフィルタを設けない（MOTOR-207, 208）。
- 旧資料の `L=0.44 cos((q1-q2)/2)` は**CAD照合が済むまで確定運動学として使用しない**。ヤコビアンは有限差分との比較で検証する。

## LQR状態

`x=[θ,dθ,x_b,dx_b,φ,dφ]^T`：仮想脚前後傾斜と角速度、車輪平均位置と速度、機体PitchとPitch角速度。

- 車輪位置は左右M3508のエンコーダ角度差を通常の一周折返し処理で累積し、車輪半径と減速比を適用して平均する（MOTOR-200, 211）。
- 車輪速度は左右M3508 RPMから換算して平均する（MOTOR-210）。滑り推定と特殊な周回数復元は初期対象外。
- Yaw PIはIMUジャイロ角速度、Roll PDはIMUのRoll角・角速度を使用する。

## IMU・鮮度

BNO055はI2Cアドレス0x28のACCGYROモード0x05を予定。加速度とジャイロから相補フィルタでPitch・Rollを推定し、取付方向を校正する。電源投入後に静止ジャイロバイアスを一度推定する。

RS06フィードバックは標準100 Hzを想定し、制御中は次の新規測定まで最新値を保持する。角度予測は初期実装では行わない。

`BALANCING`中の鮮度規定：新規IMU 50 ms、RS06各軸30 ms、M3508各軸20 ms、F303電源500 ms。各通信の送信監視は通信仕様・基板仕様を参照する。
