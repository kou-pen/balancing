# USB：有線PS5 DualSense操作仕様

**仕様ID:** PROTO-PS5-001  
**更新日:** 2026-11-09 / MOTOR-146〜184の確定操作方針を反映。

**状態:** 操作の意味は確定／HIDレポートとUSBホスト初期化は実機確認待ち。

F446の有線USBに接続されたDualSenseから前後速度、Yaw角速度、ARM/DISARMを受け取る。Piは不要。既定操作元USB_DUALSENSE、CAN_REMOTEとの切替はDISARMED中のみ。

| 操作 | 動作 |
|---|---|
| OPTIONS長押し約1秒 | ARM要求（安全条件が成立した場合だけ） |
| ○長押し | DISARM要求 |
| 前後スティック | 前後速度指令、加速度制限付き |
| 旋回スティック | Yaw角速度指令、変化率制限付き |
| USB切断／入力喪失 | 走行・Yaw目標をゼロへ漸減、倒立は継続（MOTOR-148） |
| USB復旧 | 新しい正常入力とスティックのニュートラル安定確認後に**操作のみ自動再開**。自動ARMはしない（MOTOR-149） |
| 脚長伸縮（後続） | 伸縮ボタンを押している間だけ目標脚長を変更、離すと保持（MOTOR-158） |
| ジャンプ（後続） | ボタン押下1回で開始条件確認後に自動シーケンス。実行中の追加要求は無視（MOTOR-183） |

スティックの軸・方向、デッドゾーン、最大値、CLEAR_FAULT・ジャンプ・脚長の具体割当は入力試験で確定。USB HIDのreport ID・長さ、ホスト初期化、再接続時の誤ARM防止、USB VBUSピンと供給方式を回路・実機で確認。ARMは新しい長押し成立イベントで発火させる。前後速度とYaw角速度はスティック解放で目標0へ戻し、位置・方角は保持しない（MOTOR-146,147）。
