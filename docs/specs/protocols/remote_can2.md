# CAN2：上位機器・Raspberry Piからの操作通信仕様

**仕様ID:** PROTO-REMOTE-001  
**基準日:** 2026-10-28  
**状態:** 操作意味・受信条件は設計済み。**数値IDと送信データ形式は既存Gakurobo2025由来の定義の実物照合待ち**。

Piは任意の操作元。標準操作元は有線DualSenseで、`CAN_REMOTE`と`USB_DUALSENSE`の切り替えはDISARMED中に限る。入力喪失時の自動切替は禁止。

表に示すのは**アプリケーション層の量と単位**であり、実CANのDATA[0:7]に格納する型／スケーリング／バイト順とは別。既存の送信形式が明らかになるまでは新規フレームを送信する実装を行わない。

## データの数値表現で確定する事項

- 前後速度：符号、表現範囲、単位換算（m/s）、量子化、死活判定周期。
- Yaw角速度：符号、表現範囲、単位換算（rad/s）、量子化、入力喪失の扱い。
- 操作コマンド：押下レベルとイベントの区別、連続送信時の重複無効化、送信元認証と優先順位。
- 設定変更：パラメータ番号・型・単位・適用範囲・応答、DISARMED以外での拒否。
- 非常停止：電源側の`EMERGENCY_STOP`と統一したID、受信処理、ラッチ解除条件。

**同じCAN2にはC620の標準ID=0x200／0x201／0x202がある。** 確定IDはこれらと競合せず、F303電源CANとの共存、標準／拡張フィルタ、バス負荷を検証する。作業番号：`T-PROTO-06`。
