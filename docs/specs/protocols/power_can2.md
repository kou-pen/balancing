**更新日:** 2026-11-25

## Register IDの詳細

### 共通データ（Data type = 0x01）

| Register ID | name | Priority | CAN ID（拡張） | 型 / DLC | r/w | 方向 | 概要 |
|---|---|---:|---|---|:---:|---|---|
| 0x001 | EMERGENCY_STOP | 0 | 0x00047C01 / 0x0004BC01 / 0x0004FC01 | なし / 0 | W | F446/F303/Pi→全体（順） | 非常停止。受信時にF446はFAULT、F303は遮断ラッチ |

### 電源基板（Data type = 0x10）

| Register ID | name | Priority | CAN ID（拡張） | 型 / DLC | r/w | 方向 | 周期 | 概要 |
|---|---|---:|---|---|:---:|---|---|---|
| 0x001 | POWER_ON | 2 | 0x08404801 / 0x0840C801 | uint16 / 2 | W | F446/Pi→F303 | イベント | 要求番号、投入要求 |
| 0x002 | POWER_OFF | 1 | 0x04404802 / 0x0440C802 | uint16 / 2 | W | F446/Pi→F303 | イベント | 要求番号、通常遮断 |
| 0x003 | POWER_STATUS | 2 | 0x0840BC03 | 下表 / 8 | R | F303→全体 | 100 ms | 電源状態 |
| 0x004 | POWER_RESULT | 2 | 0x08408404 / 0x08408C04 | 下表 / 8 | R | F303→F446/Pi | 応答 | 要求の処理結果 |

### POWER_STATUS

| Byte | 型 | 内容 |
|---|---|---|
| 0 | uint8 | OFF=0 / PRECHARGE=1 / ON=2 / FAULT=3 |
| 1 | uint8 | 状態フラグ（意味未確定） |
| 2–3 | uint16 | F303故障ビット（割当未確定） |
| 4–5 | uint16 | 報告連番 |
| 6–7 | uint16 | 予約=0 |

計測報告POWER_TELEMETRYは別フレームとして将来追加。電圧・電流・温度の計測可否・数値IDは未確定。

### POWER_RESULT

| Byte | 型 | 内容 |
|---|---|---|
| 0–1 | uint16 | 要求番号 |
| 2–3 | uint16 | 要求のRegister ID |
| 4 | uint8 | 結果コード（[共通定義](../../can-id-table.md)） |
| 5 | uint8 | 電源状態（上表） |
| 6–7 | uint16 | 予約=0 |

## 受信・保護

- F446/Piの両方から直接投入・遮断を要求できる。F303自身が独立して安全条件・プリチャージを判断する。受理応答は実際のONを意味しない。
- F446のARMには有効な最新のON通知が必要。BALANCING中の電源報告500 ms途絶ではFAULT。
- F303の物理非常停止・電源保護はF446とCANから独立。CAN非常停止は応答待ちなしに処理する。通常遮断も勝手に再投入しない。
- 復旧順はPOWER_ON → CLEAR_FAULT → ARM。物理停止・異常の継続中は投入不可。MOTOR-095（再起動後FAULT復元）は保留。
- 古い要求を送信待ちに蓄積しない。自動再送・CANコマンドのセッション管理は設けない（ARM内部のセッション管理とは別）。
- CAN IDの送信元は認証ではない。実CANのフィルタ、送信予算、故障フラグと旧FW互換性は未検証。
