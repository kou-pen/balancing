# BNO055 I2Cデータ仕様

**仕様ID:** PROTO-IMU-001  
**基準日:** 2026-10-27 / 仕様確定範囲のみ、未検証値はTODOで追跡。

F446に接続するBNO055はI2Cアドレス0x28、ACCGYRO(0x05)モードで使用。3軸加速度と3軸ジャイロを読み、F446側で相補フィルタを構成する。

取付方向を固定回転として補正。起動後の静止時に一度だけジャイロオフセットを求め、RAMに保持する（MOTOR-139 B）。

I2C読み出し成功は新規測定の証明ではない。センサデータが新しく更新されたかの識別方法を実機と資料で確認する。センサ更新が500 Hz未満でも状態推定は500 Hzで動作し、古いサンプルを新規とみなさない。

外乱により加速度の信頼度を低減し、単発の不正サンプルを除外する。有効な新規データが50 ms途絶えた場合はBALANCING中FAULT、DISARMED中はARM禁止。故障件数と最新有効時刻を診断ログへ記録する。
