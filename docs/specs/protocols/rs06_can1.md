# CAN1：RobStride 06通信仕様

**仕様ID:** PROTO-RS06-001  
**更新日:** 2026-11-09  
**状態:** メーカー資料でIDとデータ配置を確認。実機のモータFW版・主機ID・換算範囲は未検証。

## 通信とモータ番号

| 項目 | 内容 |
|---|---|
| バス | CAN1、1 Mbit/s、29bit拡張ID、データ長8バイト |
| モータID 1 / 2 / 3 / 4 | 左脚A / 左脚B / 右脚A / 右脚B |
| 主機（ホスト）ID | **未確定：実機と照合する** |
| Type 1の指令周期 | 250 Hz、4台分を4 msごとに送信要求し、最新トルクのみ |
| 定期報告 | Type 24で有効化、標準100 Hz |
| フィードバック受信断 | 30 msで倒立中FAULT |

モータ番号1〜4は29bitのCAN ID全体ではなく、宛先を示す下位8bit値。

### 29bit拡張IDの構造

| ビット | 内容 | 型・単位 |
|---|---|---|
| 28〜24 | 通信種別（Type） | uint5、なし |
| 23〜8 | 種別ごとの追加領域 | uint16、Type 1ではトルク量子値 |
| 7〜0 | 指令では宛先モータID、応答ではホストID | uint8、なし |

送信IDの基本式：`(Type << 24) | (追加領域 << 8) | 宛先モータID`。

| 方向 | Type（CAN ID bit28〜24） | 追加領域（bit23〜8） | 下位8bit | データ長 | 内容 |
|---|---|---|---|---|---|
| F446→RS06 | 1 = `0x01` | 目標トルク量子値 | モータID 1〜4 | 8 | 角度、角速度、Kp、Kd |
| RS06→F446 | 2 = `0x02` | モータ番号、故障、モード | ホストID | 8 | 角度、角速度、トルク、温度 |
| F446→RS06 | 3 = `0x03` | ホストID（bit15〜8） | モータID 1〜4 | 8 | 全0、有効化 |
| F446→RS06 | 4 = `0x04` | ホストID（bit15〜8） | モータID 1〜4 | 8 | 停止。Byte0=1は故障解除 |
| F446→RS06 | 24 = `0x18` | ホストID（bit15〜8） | モータID 1〜4 | 8 | 定期報告の有効化 |
| RS06→F446 | 24 = `0x18` | モータ番号、故障、モード | ホストID | 8 | 定期報告の状態値（メーカー掲載例） |

**Type 24は「コマンド」だけでなく、メーカー資料にType 24応答フレームも掲載されている。** 受信側はType 2とType 24の実機挙動を記録して確定する。

## Type 1：トルク指令の各フィールド

| 位置 | 値 | 型／並び | 物理単位 | 2025-11版の値域 |
|---|---|---|---|---|
| CAN ID bit23〜8 | フィードフォワードトルク | uint16 | N·m | -36〜36 |
| DATA[0:1] | 目標角度 | uint16・上位から | rad | -4π〜4π |
| DATA[2:3] | 目標角速度 | uint16・上位から | rad/s | -50〜50 |
| DATA[4:5] | 比例ゲインKp | uint16・上位から | N·m/rad相当 | 0〜500 |
| DATA[6:7] | 微分ゲインKd | uint16・上位から | N·m·s/rad相当 | 0〜100 |

16bit量子値の換算：`raw=round(clamp((値−下限)/(上限−下限),0,1)×65535)`。逆変換：`値=下限+raw×(上限−下限)/65535`。

トルク制御時はKp=Kd=0にするが、トルクの**安全上限はCAN表現範囲とは別**に実機仕様で定める。角度・速度指令の固定値はモータFWとの組合せで検証する。

## Type 2・Type 24状態報告

| 位置 | フィールド | 型 | 単位／換算（2025-11版） |
|---|---|---|---|
| ID bit15〜8 | モータID | uint8 | 1〜4 |
| ID bit21〜16 | 故障フラグ | 6bit | 単位なし |
| ID bit23〜22 | 動作モード | 2bit | 0=リセット、1=校正、2=運転 |
| ID bit7〜0 | ホストID | uint8 | 未確定 |
| DATA[0:1] | 実角度 | uint16・上位から | -4π〜4π rad |
| DATA[2:3] | 実角速度 | uint16・上位から | -50〜50 rad/s |
| DATA[4:5] | 実トルク | uint16・上位から | -36〜36 N·m |
| DATA[6:7] | モータ温度 | uint16・上位から | 生値×0.1 ℃ |

**故障ビット一覧**：bit21=未校正、20=拘束・過負荷、19=磁気エンコーダ異常、18=過熱、17=過電流、16=低電圧。

**資料の版差に注意：** 2026-04版の転記資料では角速度範囲に±15 rad/sという記載もある。上表の±50 rad/sを現物FWへ無条件適用せず、採用版と実測角速度を照合する。

## Type 3／4／24のペイロード

| Type | DATA[0:7] | 意味と単位 |
|---|---|---|
| 3 | 全0 | モータ有効化、単位なし |
| 4 | 全0 | 通常停止、単位なし |
| 4 | Byte0=1、残り0 | メーカー資料上の故障解除。通常停止で送らない |
| 24 | Byte6=`0x01`／`0x00`、他バイトは**実機照合待ち** | 定期報告ON／OFF、単位なし |

Type 24のメーカー表には`01 02 03 04 05 06 F_CMD`の例があり、これらのうち何が固定値・例示値か実機で確認するまで送信定数を確定しない。受信断30 ms、モータ故障、CANバスオフ時は仕様に従って保護する。

## ARM/DISARM・送信監視（MOTOR-189〜192, 196〜198）

- ARM時は全4台へType 3を要求し、それぞれ**指令送信後の新しい正常な状態報告**を確認してからトルク指令を許可する。1台でも有効化に失敗した場合は全4台の駆動無効化を要求しFAULT。
- DISARMEDへの遷移時・FAULT時はType 4通常停止を指令。DISARMED中はType 1トルク指令を停止する。無効化確認失敗は限定再送とログで追跡する。
- CAN1の3メールボックスに対して4台分を4 msごとに非ブロッキングで送信。古いトルク指令をソフトウェアキューに蓄積しない。
- RS06各軸の送信完了時刻と受信時刻を別に監視し、BALANCING中の送信長時間停止もFAULTとする（MOTOR-191）。送信完了は指令実適用の保証ではない。送信タイムアウトの具体値は実機バス負荷を測って設定。
- 角度原点は組立時にRS06へ保存する方針だが、電源再投入後の角度基準・多回転情報の復元可能性は未確認であり、実測で確定する。
