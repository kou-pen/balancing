# STM32F446 メイン制御基板 仕様

**仕様ID:** BOARD-F446-001  
**更新日:** 2026-11-09 / MOTOR-146〜224の設計決定を反映。未検証値はTODOで追跡。

**状態:** 確定方式を統合／ピン・実機検証待ち。関連：[`robot_operation`](../behavior/robot_operation.md)、[`balance_vmc`](../control/balance_vmc.md)。

## 責務

- Raspberry Pi非接続でもBNO055・RS06×4・M3508×2を使用して倒立、脚長、Roll、Yawを制御する。
- 500 Hzで状態推定、LQR、VMCおよび保護判定を実行する。RTOSは使わず、ハードウェアタイマとCAN割り込みを使う。
- CAN_REMOTE/USB_DUALSENSEの一方から操作目標を受け取り、電源基板・駆動系の状態を監視する。
- DISARMED/BALANCING/FAULTを管理する。ハードウェア非常停止を代替しない。

## 入出力

| I/F | 接続 | 周期／注意 |
|---|---|---|
| CAN1 | RobStride 06、ID 1〜4 | 250 Hzトルク指令／10 ms定期報告 |
| CAN2 | C620×2 | 500 Hz共通電流指令 |
| CAN2 | STM32F303 | 100 msごとの電源状態報告を監視 |
| CAN2 | Raspberry Pi（任意） | 操作指令、非常停止、パラメータ調整 |
| I2C | BNO055、アドレス0x28 | ACCGYRO=0x05、新規測定の有効性管理 |
| USB | 有線PS5 DualSense | 主操作元の既定値 |

**ピン監査:** 既存設計ではPB14/PB15のOTG_HS（内蔵FS PHY使用構成）とCAN2_TXのPB13、VBUS sense競合を考慮。実回路とCube/HAL設定を照合し、USB VBUS検出方式を確定すること。USBホスト機能の成立も実機で検証する。

## タイミング

制御周期は2 ms。RS06送信は4 msごとに4台分の最新指令を送信要求し、3つのCAN送信メールボックスの空きに応じて順に処理する。古い送信待ちトルクを蓄積しない。C620は2 msごとに送信する。DISARMED中はRS06を無効化して通常トルク送信を停止し、C620へ0電流を継続送信する。各センサの新規更新周期は制御周期と区別する。

連続3周期相当の制御欠落（6 ms）をBALANCING中に検出した場合はFAULT。IWDG約500 msは、制御停止時に最終的にリセットさせる補助機構として利用し、正常処理未完了のまま無条件に更新しない。

## 起動・駆動許可

起動直後はDISARMED。ARMにはPS5の明示的操作、IMU・RS06×4・C620×2・F303電源と原点の正常性、検証済みゲインと安全制限値を要求する。**初期姿勢や脚長の指定範囲そのものはARM許可ゲートにしない**（MOTOR-151）。制御中の機械的保護限界は別に維持する。RS06×4へまとめて有効化を要求し、新しい正常応答が全台から届くまでトルク出力しない。失敗時は全台無効化・FAULT。ARM時は現在の脚長を目標に初期化し、トルクの急変を制限する。起き上がり動作の詳細のみMOTOR-132として保留。

## 異常処理

- M3508受信断20 ms、RS06受信断30 ms、IMU有効な新規データ50 ms、F303電源状態報告500 msでBALANCING中FAULT。
- CAN Bus-off、センサ姿勢推定不能、機械的・姿勢保護限界、過温度、ハード故障も各仕様に従いFAULT。
- **MOTOR-191／194により送信監視を追加：** RS06各軸のCAN送信完了時刻、C620共通指令フレームの送信完了時刻と各モータの受信時刻を監視する。送信監視をしない旧記述（MOTOR-111相当）は更新済み。送信完了は駆動適用の証明ではない。
- FAULT時の電源断は独立したF303経由の非常停止仕様とは区別する。CAN非常停止受信時はF446側FAULT、F303側OFFの両方を要求する。

## 設定と所有権

制御パラメータはファームウェア初期値、変更はDISARMED中にCANからRAMへ。起動ごとのFlash書込みは行わない。Driverは通信、Estimatorは物理状態、Controllerは指令計算、Safetyは許可判定を所有する。

## 非目標

起立、脚長可変・ジャンプ、フル3D推定、Pi接続の必須化、膨大な自己診断機能は初期非目標。初期は固定脚長での基本バランシング（MOTOR-213）を完成させる。
