# ジャンプ制御仕様（後続開発）

**仕様ID:** BEHAV-JUMP-001  
**更新日:** 2026-11-09  
**状態:** MOTOR-168〜187で設計方針を決定。**初期の固定脚長バランシング（MOTOR-213）の実装対象外**。閾値、推力、機構限界、着地脚長、ゲインは未検証。

## 実装方針

既存の500 Hz制御ループ、脚長PD、VMC、接地推定、安全状態を再利用する。ジャンプ専用タスクや左右別々の状態機械を作らない。状態機械は機体全体で1つ。

1. `PREPARE`：**静止かつ安定して両輪接地**している場合だけ開始し、離陸準備用脚長へ移行。
2. `TAKEOFF`：左右の脚に等しい一定**目標推力**を指令し、VMCとガスシリンダ補償で各RS06トルクへ変換。脚の伸長限界接近、離陸検出、最大駆動時間のいずれかで解除。離陸未確認なら自動FLIGHT移行しない。
3. `FLIGHT`：M3508の電流指令は0。RS06は弱めの脚長PDで固定の着地脚長を保持。空中ピッチ姿勢制御は初期導入しない。
4. `LANDING`：左右どちらかの接地が確認された時点で移行。接地した側だけ柔らかい着地PD、未接地側は空中PD。脚の剛性・減衰を調整し、ガスシリンダ補助トルクを補償する。
5. `RECOVERY`：両輪接地、脚の伸縮速度、機体Pitch/Roll角速度が許容範囲で一定時間安定したら通常BALANCINGへ復帰。タイムアウト時は安全条件を見てFAULT／復帰を区別する。

## 入力・接地推定

- PS5のジャンプボタン**押下イベント1回**で開始。押し続ける必要はなく、実行中の再押下は無視・予約しない（MOTOR-183）。
- ジャンプ中の走行・Yaw操作を無視し、復帰後に現在のスティックから再開（MOTOR-184）。
- 接地状態はIMU・RS06角度／角速度／トルク情報・M3508回転速度等から**左右別々に推定**（MOTOR-170, 171）。単一センサに断定的に依存せず、不確実な場合はUNKNOWNを使う。
- 片輪接地では制限制御とし、通常の両輪接地LQRをそのまま適用しない（MOTOR-169, 172）。細かな推定アルゴリズムは実測で検証する。

## 制限・異常時

- `TAKEOFF`専用RS06トルク上限を設定し、通常上限より厳しく調整可能にする（MOTOR-187）。最終トルクはモータ別クリップ。
- 離陸に失敗した場合も、両輪接地が安定していれば通常制御への復帰を優先。復帰不能のまま無期限に駆動しない（MOTOR-185）。
- 姿勢不良、IMU/RS06/M3508通信異常、手動DISARM、非常停止を最優先する。
- 50 cmジャンプは**最終的な目標**であり初期テスト合格条件ではない。まず低高度・低トルク・支持治具で段階検証する。

## 後回しにするもの

推力の脚長・速度依存プロファイル、空中の車輪反力によるピッチ制御、着地脚長の動的最適化、走行中のジャンプ、専用の左右状態機械、3次元の最適化制御は初期実装しない。
