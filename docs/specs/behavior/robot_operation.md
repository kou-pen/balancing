# ロボット動作仕様（利用者から見える振る舞い）

**仕様ID:** BEHAV-001  
**更新日:** 2026-11-09  
**状態:** 動作方針は設計決定済み。STM32への組込み・実機検証は未完了。

関連：[制御](../control/balance_vmc.md)／[ジャンプ](jump.md)／[図](../../diagrams.md)。

## 初期の適用範囲

MOTOR-213：**固定脚長の基本バランシングを最初に完成させる**。PS5操作による前後走行、Yaw旋回、Roll保持、脚長保持、ARM/DISARM/FAULTを対象とする。脚長可変・ジャンプ・自動起立は後続機能であり、初期完成条件に含めない。初回実機試験は支持治具と低トルク上限を使用する。

## 安全状態と操作（MOTOR-148〜157）

| 状態 | 動作 |
|---|---|
| `DISARMED` | RS06駆動無効。M3508には電流0を500 Hzで送信。通信・センサ監視継続。 |
| `BALANCING` | LQR・VMC・Yaw PI・Roll PDと脚長保持を実行。 |
| `FAULT` | 重大異常を記録・保持し、全モータ駆動を即時禁止。送信可能な停止指令を出す。 |

- 電源投入時は必ずDISARMED。ARMはPS5からの**明示的操作**のみ（MOTOR-150）。
- ARM許可ではセンサ・全モータ・電源・原点・検証済みパラメータの正常性を確認する。**機体の傾きや脚長の姿勢範囲そのものはARM許可条件にしない**（MOTOR-151）。機械的な可動限界を守る制御中の保護とは区別する。倒れた姿勢からの起き上がり動作は後で設計する。
- ARM時はRS06 4台にまとめて有効化要求を送り、**全台から有効化後の正常応答**を確認してからトルク制御を開始（MOTOR-197）。失敗時は全台を無効化しFAULT（MOTOR-198）。
- ARM時にPIなどの内部状態を初期化し、トルクの急変を制限する。実際の左右脚長を脚長目標の初期値とする（MOTOR-152, 159）。
- 手動DISARMは即時駆動禁止。RS06に無効化指令を送り、その後の通常トルク送信を停止。M3508へは電流0を継続送信（MOTOR-153, 195, 196）。
- FAULTは原因解消だけで自動復帰しない。**明示的なCLEAR_FAULTでDISARMEDへ、別のARMでBALANCINGへ**（MOTOR-154, 155）。
- 非常停止は状態機械と別の**最優先の駆動禁止条件**。解除しても自動ARMしない。物理非常停止はF446のソフトウェアやCAN通信に依存しない電源遮断手段（MOTOR-157）。

## 通常運転（MOTOR-146, 147, 149, 158, 184, 199, 203, 204）

- 前後スティックは目標速度、旋回スティックは目標Yaw角速度を生成し、それぞれ変化率制限を掛ける。スティックを離すと目標を0へ戻す。**元の位置や方角に戻そうとしない。**
- LQRは左右車輪の平均位置・速度を使用し、移動する位置基準で走行・停止を扱う。Yaw PIにはジャイロの角速度、Roll PDにはIMUのRoll角と角速度を使う。
- Roll目標は通常走行・旋回中とも0°。遠心力フィードフォワードや旋回時の機体傾斜は初期実装しない。
- 将来の脚長操作では、ボタンを押している間だけ共通脚長を伸縮し、離すと現在目標値を保持する（MOTOR-158）。
- PS5入力が途絶したら目標速度・Yaw角速度を0へ減速し、バランスは維持する。通信復旧時は**正常な新規入力とニュートラル安定確認後に自動操作再開**。手動再ARMは不要（MOTOR-148, 149）。FAULT中やDISARMED中に自動ARMしてはいけない。
- ジャンプ中の走行・旋回指令は無視し、復帰後は現在のスティック値から新たに目標を生成する（MOTOR-184）。

## 駆動と保護

- RS06指令250 Hz、M3508電流指令500 Hz。送信完了とフィードバック受信の両方向を監視。送信遅延時は古いトルク指令を蓄積しない（MOTOR-189〜194）。
- モータトルク・電流は個別に安全上限で制限する。脚側は複雑な優先配分を初期実装しない。単なる飽和はFAULTにしない。
- 重大FAULT時、送信が可能なら停止指令を直ちに出すが、通信断では届かない可能性がある。物理非常停止とモータ側タイムアウトも必要。

## 操作割当・未決定

既存の暫定操作割当はOPTIONS長押し約1秒ARM、○長押しDISARM。USB HIDの実際のボタンID・デッドゾーン・CLEAR_FAULT・ジャンプ・脚長ボタンは実機確認後に確定する。

MOTOR-095：電源断・再起動後のFAULT保持方式は保留。MOTOR-132：起き上がり・立ち上がり全体のシーケンスは保留（**ARM脚長初期値はMOTOR-159で「現在値」に確定**）。

DISARM/FAULT後の自立、停電時の姿勢保持、滑りのない位置推定、未検証の脚姿勢からの自動起立は保証しない。
