# 開発ロードマップ

まず**固定脚長で安定して倒立・走行・停止できること**を目指します。可変脚長とジャンプは、その後の段階です。

## 3つの段階

| 段階 | 達成したいこと | 完了の基準 |
|---|---|---|
| **P0：固定脚長** | 起動、倒立、前後走行、旋回、安全停止 | 支持治具から始め、実機で再現・計測できる |
| P1：可変脚長 | 目標脚長を変えながら安定化 | 現在脚長を初期目標にした制御とゲイン補間を検証 |
| P2：ジャンプ | 離陸・着地・復帰 | 段階的な実機試験で安定動作を確認 |

## P0の進め方

| 順序 | 作るもの | 現在地 |
|---|---|---|
| 1 | [F446周期処理と通信](f446.md)、[プロトコル](protocols.md) | C++入口・CAN codec・送信要求モデルをホスト検証。CubeIDE 6ソースビルドPASS。HAL通常運転統合と実通信は未完成 |
| 2 | [脚運動学・状態推定](control.md) | 6節リンク、原点、センサ値の結合が未実装 |
| 3 | [固定脚長モデルとLQR](control.md) | 一部のC11数値処理はホスト検証。実機パラメータと制御器の統合は未完成 |
| 4 | [脚長・Roll・Yaw制御と安全状態機械](control.md) | 安全状態機械はホスト試験済み。仕様不一致の一部と制御統合が残る |
| 5 | [結合・支持治具・実機確認](verification.md) | 実機試験は未実施 |

**P0の完了条件**は、ARM・姿勢保持・前後走行・旋回・DISARM/FAULTを実機で再現し、電流・トルク・周期・ログを残すことです。PC上のPASSだけでは達成したことになりません。

## 次の段階と前提

P1では、MOTOR-159の決定どおり**ARM時の脚長目標は現在脚長**にします。可変脚長でのゲイン補間などの詳細は [制御TODO](control.md) にあります。P2は [ジャンプTODO](jump.md) を参照してください。

再起動時のFAULT復元（MOTOR-095）と起き上がり手順（MOTOR-132）は保留です。RS06原点、駆動符号、機械特性、トルク上限、実機用LQRゲインも未検証のままです。確定事項と未検証事項は [仕様ID索引](../spec-index.md) と [検証記録](../verification/index.md) から追跡できます。
