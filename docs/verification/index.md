## 検証状態の区別

| 表記 | 意味 |
|---|---|
| PASS | 記載された環境と対象で試験成功 |
| FAIL | 試験実行後に失敗 |
| NOT RUN / NOT VERIFIED | 未実施、または合否に必要な証拠がない |
