# F303電源通信コーデックのホスト検証

対象：PROTO-PWR-001、T-PROTO-05/11、T-F303-05。2026-11-25。

## 実装範囲

| ファイル | 役割 |
|---|---|
| PowerBoardCodec.hpp | ワイヤ上の電源状態・要求・応答のデータ型と公開API |
| PowerBoardCodec.cpp | POWER_STATUS、POWER_ON/OFF、POWER_RESULT、EMERGENCY_STOPの符号化・復号 |
| ProtocolPayload.hpp | 共通のResultCode列挙 |

既存ProtocolId/ProtocolPayloadを利用し、ID・IDE・DLC・方向・列挙値・予約領域を検査する。フラグとF303故障ビットは未確定なので生値として保持する。電源報告の連番も保持するが、鮮度・周回・重複の判定は行わない。受理応答は電源投入の完了とは別である。DLC0の非常停止は有効ペイロードがないため配列の未使用バイトを検査しない。

## 検証

- CTest 31/31 PASS。
- 仕様の10個の具体ID（共通3、電源7）と独立した既知バイト列、全正常状態、全正常結果、要求番号の端点を照合。
- 不正列挙、予約バイト、IDE、DLC、未割当ID、別サービス、0x700・予約上位11bit、ID範囲外を拒否。
- テストはホスト内だけで実行。フラグのテスト値は人工値であり実機の意味を決定しない。

## 非変更・保留

実CAN2配送、PowerBoardServiceへの入力、F303の電源操作、ARM、物理非常停止、RS06/C620、実機フィルタを変更しない。F303既存FWとの互換、状態フラグ・故障ビットの意味、ARMクロスビルド、実機通信は未検証。T-PROTO-05/11とT-F303-05は未完了のままとする。
